# 補丁上傳說明 — 資訊服務業統計表（4 個 CSV）

> 目標專案：勞動合規風險助手_2026 咕咕嘎嘎
> 上傳路徑：Data Importer → Import Data → 依序新增 4 條 Flow

---

## 操作流程（每個 CSV 做一次）

1. 進入 `cloud.geminidata.com` → 咕咕嘎嘎 → **匯入原始資料**
2. 點右上角 **Import Data** → **Add New Flow**
3. **Information 步驟**：Flow Name 填下方表格中的「Flow 名稱」
4. **Sources 步驟**：Upload 上傳對應 CSV 檔案
5. **Models 步驟**（關鍵）：
   - 表格式建模（不是畫布拖拉）
   - 選 Unique Key 欄位（見下表）
   - 填 Categories（節點標籤，見下表）
   - 其餘欄位點 **Add All as Properties**
   - 點 **Save**
6. **Review 步驟**：確認無誤
7. 列尾播放鈕 → **Start**，等狀態變 Completed

## 注意事項

- **不需要清空畫布或重跑既有 46 條 Flow**：這是純新增，不影響現有資料
- 4 條 Flow 都是獨立節點、無關係，Model 步驟不需拉關係線
- 若 Categories 填錯（如填成欄位名稱而非節點標籤），上傳後要刪 Flow、重新建
